# Struktur alte Website Frauenverein Büren

> Inventar der bestehenden Seite. Basis für die Zuordnung zu Payload-Collections.
> Pro Seite eine Zeile ausfüllen. Typ bestimmt, wohin der Inhalt wandert.

## Typ-Legende
- **Info** = statische Info-Seite → Collection `Pages`
- **Event** = einmaliger Anlass → Collection `Activities` (type: event)
- **Kurs** = Kurs mit Anmeldung/Zahlung → Collection `Activities` (type: course)
- **Flyer** = PDF-Download → Collection `Flyers`
- **System** = Impressum, Datenschutz, Kontakt → `Pages`
